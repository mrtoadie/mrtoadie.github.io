podman info | grep -i why Raspberry Pi Zero 2W · 512 MB RAM
Warum Podman statt Docker für Dynacat? Docker bringt einen zentralen Daemon mit, der als root läuft — auf einem Gerät mit 512 MB RAM ist das reine Verschwendung, und der Daemon ist zudem eine Angriffsfläche. Podman läuft daemon-los und rootless: Container starten als normale systemd-User-Services, Ressourcen sparen, Rechte trennen. Auf einem Pi Zero zählt jedes Megabyte. Es bleibt genügend Luft um Caddy und Unbound ebenfalls auf dem Zero laufen zu lassen.
velero backup create --help Go · Charm Huh
Warum velero-manager? Velero ist mächtig, aber seine CLI ist es auch: Schedules anlegen, manuelle von geplanten Backups unterscheiden, den richtigen Namespace treffen — alles erfordert YAML oder lange Flags. Genau diese Wiederholungen hat der Manager in eine interaktive TUI verbannt: Menüs statt Dokumentation lesen, Auswahl statt Flags raten. Gebaut in Go mit Charm Huh — bewusst statt Bubble Tea, weil die Dialoge sich wie ein natives CLI anfühlen sollen, nicht wie eine App im Terminal.
git push origin cluster.json Bash · GitHub API
Warum publiziert der Collector über GitHub? Weil GitHub Pages die Antithese zum betriebenen Server ist: keine Runtime, keine Datenbank, nichts, das gepatcht werden will. Der Cluster pusht eine einzelne JSON-Datei via API, der Browser holt sie sich per fetch — statisches Hosting als Livestream. Fällt der Cluster aus, zeigt die Seite trotzdem den letzten bekannten Zustand samt Zeitstempel. Die Infrastruktur, die die Daten transportiert, kann nicht abstürzen, weil es sie schlicht nicht gibt.
