Why use Podman rather than Docker for Dynacat?
Docker comes with a central daemon that runs as root — on a device with 512 MB of RAM, this is a complete waste, and the daemon also presents a vulnerability. Podman runs daemon-free and rootless: containers start as normal systemd user services, saving resources and isolating privileges. On a Pi Zero, every megabyte counts. There’s still enough headroom to run Caddy and Unbound on the Zero as well.

Why velero-manager?
Velero is powerful, but so is its CLI: creating schedules, distinguishing manual backups from scheduled ones, selecting the correct namespace — all of this requires YAML or long command-line flags. It is precisely these repetitive tasks that the Manager has banished to an interactive TUI: navigating menus instead of reading documentation, making selections instead of guessing flags. Built in Go with Charm Huh — deliberately chosen over Bubble Tea, because the dialogues are meant to feel like a native CLI, not like an app in the terminal.

Why does the Collector publish via GitHub?
Because GitHub Pages is the antithesis of a managed server: no runtime, no database, nothing that needs patching. The cluster pushes a single JSON file via the API; the browser retrieves it using fetch — static hosting as a live stream. If the cluster goes down, the page still displays the last known state, complete with a timestamp. The infrastructure that transports the data cannot crash, because it simply does not exist.
