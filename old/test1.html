Real problems solved (this is where the learning happened):

Velero Metrics Missing in Prometheus
Root-caused ServiceMonitor label mismatches and port-forward conflicts; built a custom monitoring config and dedicated Grafana dashboards for Velero.
k3s Node Rejoin Failures & Token Mismatches
Diagnosed drifted worker nodes refusing to rejoin after upgrades. Learned when re-registration fixes it — and when a clean reimage is the honest option. Data-dir migration off SD cards onto USB-SSD followed.
cgroup Memory Limits on Raspberry Pi
Tuned boot cgroup parameters so Kubernetes sees correct allocatable memory on 1–2 GB nodes.
ARM Image Pull Failures (Platform Mismatch)
Traced "ImagePullBackOff" on Raspberry Pis to amd64-only base images; now multi-arch images are checked before any rollout.
OpenVPN Replay Detection Errors
Resolved tunnel establishment failures tied to replay-window misconfiguration.
