Software & Tools Self-Hosted Stack

Nicht was ich installiert habe — sondern warum ich es ausgewählt habe

Ingress & DNS

Traefik
Ingress-Controller für alle internen Dienste (grafana.local, forgejo.local)
"k3s bringt Traefik mit, nginx-ingress wäre eine zusätzliche Schicht gewesen."
Unbound
Recursive DNS Resolver auf Raspberry Pi Zero
"FRITZ!Box erlaubt keine eigenen DNS-Einträge im aktuellen Tarif. Unbound löst *.local auf Cluster-IPs."

Monitoring & Alerting

Prometheus + Grafana
Node Exporter, kube-state-metrics, custom ServiceMonitors
"Standard-Stack mit Helm chart kube-prometheus-stack. Eigene Dashboards für Velero-Metriken."
Uptime Kuma
HTTP/TCP/Ping-Checks auf alle Dienste
"Einfache Einrichtung, sieht gut aus, überwacht auch Dinge außerhalb des Clusters (NFS, MinIO)."
Dynacat
Dashboard auf Raspberry Pi Zero (Podman)
"Leichtgewichtig, SSH-basiert, zeigt Node-Metriken ohne Kubernetes-API zu benötigen."

CI/CD & Version Control

Forgejo
Git Hosting (Fork von Gitea)
"GitHub ist öffentlich. Forgejo lokal für private Repos, kein Internet-Zugriff nötig."
Ansible
Configuration Management, Paket-Synchronisierung
"Playbooks vergleichen pakete auf workers, installieren fehlende, exportieren Specs als JSON."

Storage & Backups

Velero + MinIO
Kubernetes Backup/Restore auf lokales S3-kompatibles Ziel
"Backup von Metadaten + PVs. Restore getestet. MinIO läuft in Docker auf Desktop, nicht im Cluster."
NFS Subdir Provisioner
Dynamische PersistentVolumes über NFS
"Statt local-path: Daten bleiben erhalten, wenn Pod neu geplant wird. Performance ausreichend für kleine DBs."

Development & Utilities

k9s
Terminal-UI für Kubernetes
"Schneller als `kubectl get pods -A`, Filter, Live-Logs, Port-Forwarding."
FreshRSS
RSS-Reader (Migration geplant zu k3s)
"Aktuell auf separater VM. Docker-Compose einfach zu migrieren, wenn Zeit ist."
